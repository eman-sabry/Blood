# 🩸 LifeDrop - Blood Donation System

LifeDrop is a full-stack blood donation platform that connects donors with hospitals in real time to save lives faster and more efficiently.

The system includes:
- 👨‍💻 Donor Mobile App
- 🏥 Hospital Web Dashboard
- 🧑‍💼 Admin Web Panel

---

## 🚀 Features

### 👤 Donor App
- User registration with medical information
- Blood type selection
- Location-based matching with nearby hospitals
- Real-time notifications for donation requests
- Donation status tracking (Accepted → On the way → Donated)
- Donation history
- Profile management

### 🏥 Hospital Dashboard
- Hospital registration with verification
- Blood stock management
- Create blood donation requests
- Track available donors
- Notifications system

### 🧑‍💼 Admin Panel
- Approve or reject hospitals
- Manage users and donations
- View analytics and statistics
- Monitor system activity

---

- React Router
